# G3：入站安全闭环（Bearer + L1/L2 卡片 + PII 过滤 + ops.log 审计）

> 契约 SSOT：docs/design/thirdconnect.md §7（入站安全闭环）/ §1.2.6（信任卡片）/ §10.4（TC12 L2 45s 熔断）。
> 定位：Bearer 最小件已随 G1 落地（`gateway_server.requiredToken`）；本卡交付其余三件——L1/L2 权限卡片拦截、PII 出站过滤、ops.log 入站审计。

## 1. 交付物

1. `lib/gateway/gateway_security.dart`——`GatewaySecurity` 安全管线（裁决 → 执行 → 过滤 → 审计）：
   - **L1/L2 裁决复用宿主 SSOT**：`PermissionGateway.classify`（annotations `readOnlyHint` + 本地只读白名单双源，双缺从严）；
   - **L2 确认卡**：`DialogGateDelegate` 经全局 `appNavigatorKey` 在手机屏弹 AlertDialog（工具名 + 参数预览 + 「本网关会话记住」勾选）；**45s 显式超时**双保险——delegate 超时负责收 UI（Timer pop 回拒绝），guard 超时负责回包（`Future.timeout` 主动拒绝，TC12：PC 立即停转不悬挂）；应用不在前台（navigator 为空）= 无确认界面一律拒绝（保守缺省）；
   - **会话豁免（C7 口径）**：批准时勾选「记住」→ 该工具网关生命周期内静默放行（内存态），`resetSessionGrants()` 在 controller.stop() 调用；
   - **拒绝语义（§12 同口径）**：`user_rejected` 包装为正常结果 `isError=false` 回传 PC（拒绝≠系统错误）；
   - **PII 出站过滤（fail-closed，D4）**：工具结果回 PC 前过 `PiiRedactionSession` 四类遮蔽（手机号/邮箱/身份证/银行卡，per-request 会话）；遮蔽失败**整包转 isError 拦截帧，严禁明文出站**；progress 帧 `message` 用 `redactSync` 同步遮蔽（瞬态帧不并会话映射，终局结果由会话级遮蔽兜一致性）；
   - **ops.log 入站审计**：每次已路由 tools/call（含拒绝/拦截/失败）落 `server='gateway'` JSONL 流水（ok/durationMs/error，error 200 字截断）；审计失败 DEGRADE 留痕不阻断。
2. `lib/ui/navigator_key.dart` + `main.dart` 挂 `navigatorKey`（后台弹层入口）。
3. `mcp_gateway_handler.dart` 接线：`security` 字段（null=直通，仅测试）；toolsCall 已路由调用全部过 guard；progress message 遮蔽。
4. `gateway_controller.dart` 装配：`GatewaySecurity(delegate: DialogGateDelegate())` 构造注入；`_assemble` 期注入与 face 级审计同源的 opsLog；stop 清豁免。

## 2. 关键决策

- **PII 过滤方向 = 出站（结果回 PC）**：围栏语义是「防设备 PII 离开设备」；入站 arguments 来自 PC 侧自有数据，遮蔽会破坏工具语义，不做；
- **L2 裁决不整用 `PermissionGateway.execute`**：其 `ToolExecutor` 接口无 progress 通道（并发下串流），仅复用 `classify`（公开直测面）+ `GateDelegate`/`GateDecision` 类型；45s 超时是网关特有（宿主面无此需求），故自管 L2 流程；
- **双重 45s**：delegate Timer 收 UI + guard timeout 回包，互不依赖（UI 卡死不影响 PC 侧及时收到拒绝）。

## 3. 验收（全部通过）

- `flutter analyze lib/gateway lib/main.dart lib/ui/navigator_key.dart test/gateway` → 0 issue；
- `flutter test test/gateway/` → 10/10 过（新增 6 例）：
  1. L1（readOnlyHint）静默放行，不经确认卡；
  2. L2 无确认界面（无人值守）拒绝且不执行；
  3. L2 批准并记住 → 二次免确认，`resetSessionGrants` 后重新确认；
  4. 确认超时主动拒绝（50ms 缩窗验证）；
  5. PII 遮蔽：`13800138000` → `[手机号1]`，原文不出站；
  6. ops.log：拒绝（含 user_rejected 标记）与成功均落 `server=gateway` 流水。

## 4. 遗留

- L2 确认卡的 `FULL_SCREEN_INTENT` + 短时 WakeLock 震动亮屏（TC12 醒目呼叫）为原生侧能力，归 G4（前台保活同批原生改动）；
- Binder `getCallingUid()` 信任卡片白名单（§1.2.6，本地插件第三方接入）归独立任务（见断点）；
- 45s 内 PC 侧 Keep-Alive 进度帧注入（tools/call SSE 等确认期间喂狗）留 TC12 收口。
