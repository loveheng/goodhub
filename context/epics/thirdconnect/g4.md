# G4：前台保活（ForegroundService + WifiLock + WakeLock）

> 契约 SSOT：docs/design/thirdconnect.md §7（保活条款：开启「PC 远程连接」时启动 ForegroundService（通知栏常驻）+ WifiLock + WakeLock，避免息屏断连）。
> 定位：原生侧（Kotlin）为主 + Dart 侧通道联动；起停与网关开关同生命周期。

## 1. 交付物

1. `android/.../GatewayForegroundService.kt`——前台保活服务：
   - `foregroundServiceType="connectedDevice"`（minSdk 34 强制类型化），前置权限以 `CHANGE_WIFI_STATE` 满足（Android 14 对该类型要求的 precondition 之一）；
   - `WifiLock(WIFI_MODE_FULL_HIGH_PERF)` + `WakeLock(PARTIAL_WAKE_LOCK)`，`setReferenceCounted(false)`，onDestroy 统一释放；
   - 通知栏常驻（IMPORTANCE_LOW 不打扰，点击回 MainActivity）；`startForegroundService` 后 onStartCommand 立即 `startForeground`（5s 预算内）；
   - 起服失败（OEM 限制/权限缺失）捕获 `[DEGRADE]` 降级：网关仍可用（仅前台时），禁崩宿主；`START_STICKY` 被杀自动拉回。
2. `android/.../GatewayServiceBridge.kt`——MethodChannel `goodhub/gateway_service`（start/stop）；顺带补 `POST_NOTIFICATIONS` 运行时授权请求（Android 13+ 通知可见性；未授权仅通知隐藏，服务照常）。
3. `AndroidManifest.xml`——补齐权限七项（INTERNET / ACCESS_WIFI_STATE / CHANGE_WIFI_STATE / WAKE_LOCK / FOREGROUND_SERVICE / FOREGROUND_SERVICE_CONNECTED_DEVICE / POST_NOTIFICATIONS）+ `<service android:foregroundServiceType="connectedDevice">` 声明。
4. `lib/gateway/gateway_service_channel.dart`——Dart 通道封装；`GatewayController.start/stop` 联动起停；原生不可达（单测/无引擎）`MissingPluginException` 捕获 DEGRADE 不阻断网关起停。

## 2. 验收（全部通过）

- `./gradlew :app:compileDebugKotlin` → exit 0；
- `./gradlew :app:processDebugMainManifest` → exit 0（权限与 FGS 声明合并合法）；
- `flutter analyze lib/gateway` → 0 issue；`flutter test test/gateway/` → 10/10 无回归；
- 真机验证路径（待设备）：⚙ 开网关 → 通知栏出现「GoodHub 网关运行中」常驻通知 → 息屏后 PC 仍可 `:8766/mcp` 调用。

## 3. 遗留

- TC12 L2 醒目呼叫（`FULL_SCREEN_INTENT` + 短时 WakeLock 震动亮屏弹全屏授权卡）：需专用 activity + 全屏通知基建，独立收口（本轮 PARTIAL WakeLock 已保证确认卡所在进程存活，但息屏时卡片不可见）；
- 电池优化白名单（REQUEST_IGNORE_BATTERY_OPTIMIZATIONS）未申请——部分 OEM Doze 仍可能限网；视真机表现后补。

## 4. 落点

- 原生：`android/app/src/main/kotlin/com/zzh/goodhub/{GatewayForegroundService,GatewayServiceBridge,MainActivity}.kt`、`android/app/src/main/AndroidManifest.xml`；
- Dart：`lib/gateway/gateway_service_channel.dart`、`lib/gateway/gateway_controller.dart`。
