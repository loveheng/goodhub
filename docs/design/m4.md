> **T6 设计注记（2026-10-11 立项，施工分解 T6-1~T6-4）**：真机冒烟全绿后多服务需求落地（用户），F1.1~F1.3 组解冻。**单 Server 假设清单（取证）**：① McpToolFace 单实例；② PermissionGateway 单目录 + 本地白名单裸名表；③ HydratingExecutor.targetServerId 单值；④ AgentLoop.refServerId 恒 'goodshare'（put 端句柄来源）；⑤ memoryPromptSection 单 serverScope；⑥ 连接配置单端点 SharedPreferences。**设计要点**：
>
> - **ToolRouter（F1.2）**：`lib/coordinator/tool_router.dart`——非装饰器，`implements ToolExecutor` 直接持 `Map<serverId, McpToolFace>`；对外工具名 `<serverId>__<toolName>`（coding-standards §4 双下划线仅分隔符），execute 剥前缀路由（face 收裸名，server 零感知）；`serverFor(prefixed)` 供 AgentLoop put 端句柄来源；激活集会话粒度（router 实例随会话建）；**未激活 server 的调用 → isError 引导先 activate_server_tools**（幻觉调用防线，N2 常驻开销恒定的守门面）。
> - **链路序**：Loop → SkillActivation → MemoryTool → Hydration → Gateway → **ToolRouter** → faces——Gateway 见前缀名（确认卡/L1L2 分类对象），Hydration 维持「先注水再裁决」；$ref 句柄自带 server 绑定（M2.5 就绪），**跨源联合授权卡首次真跑**（A 服务出参 → B 服务入参）。
> - **Gateway 前缀适配**：loadCatalog 收前缀化 schemas（annotations 随名挂 → hint 查询天然兼容）；classify 本地白名单查表**剥前缀**（serverId/toolName 均不含 `__`，split 安全）。
> - **AgentLoop 去单 Server 化**：增可选 `serverResolver(String prefixedName) → serverId`（装配层接 router.serverFor）——`_governedContent` put 端 serverId = resolver(call.name) ?? refServerId；AgentLoop 对多 Server 保持无知（只调 resolver）。
> - **JIT 两级发现（F1.3，T6-3）**：常驻元工具 `get_connected_apps()`（列 serverId + 一行摘要）+ `activate_server_tools(server_id)`（注入该 server 全量工具 schema，L1 静默 + 药丸）+ `use_server(server_id)`（聚焦独占指定服务，2026-10-14 增：聚焦面经 `ToolRouter.focusedSchemas()` 下发，传 "all" 恢复全量，聚焦顺带激活幂等；非聚焦 server 直接调用被 router 独占守卫 isError 引导）；静态首级摘要常驻「## 已挂载服务」节（装配层拼，标注自动生成）；已激活 Schema 预算 1200T 超限精简模式（name + description 首句，architecture 待拍板项已定口径）；未激活工具不进 tools 列表（N2）。
> - **多服务配置（T6-1）**：`ServerEndpointStore`（lib/mcp/）——endpoint/name JSON 文件 + **apiKey 走 SecureKeyValue**（F1.12 密钥纪律，禁明文落盘）；旧单端点 SharedPreferences 迁移（load 时缺文件且旧键在位 → 迁移写盘）；ChatPage ⚙ 改服务列表管理（加/删/编辑）。
> - **记忆注入多作用域**：memoryPromptSection 收 `List<String> serverScopes`（user 恒在 + 全部已连并入；预算截断兜底，T7 调参收敛到已激活）。
