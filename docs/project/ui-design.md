# GoodHub UI 设计规范 · 运行时控制台风格

> GoodHub 视觉与交互语言 **SSOT**。基调：工业实用主义 × 现代控制台质感——高密度、低装饰、确定性状态。
>
> **本文零外引**：不挂钩外部文档、不使用外部代号；外部一律单向指向本文。
>
> **总纲（三拒绝，全程有效）**：① 禁过度拟物；② 禁大面积渐变发光；③ 禁玩具式大圆角。
>
> **适用范围**：`lib/ui/` 一切界面（现存与未来新增）。

## 1. 色彩 Token（功能状态驱动）

背景一律低饱和冷中性色；高对比色彩**只用于系统状态**，禁装饰性用色。

| 角色 | Token（`console_tokens.dart`） | 参考值（深 / 浅） | 适用 |
| --- | --- | --- | --- |
| 底色基底 | 主题背景 | Zinc 900/950 · Slate 50/100 | 页面与阅读轨底色 |
| L1 就绪/成功 | `l1Ok` / `l1Info` | Emerald 400 · Cyan 500 / 600 系 | 只读工具执行、探活正常、轻提示 |
| L2 写操作警示 | `l2Warn` / `l2Accent` | Amber 500 · Orange 400 | 写操作确认、`$ref` 联合授权卡 |
| 危险/熔断/中止 | `danger` / `dangerDeep` | Rose 500 · Crimson | 中止键、熔断排查卡、准入被拒 |
| 数据指针 | `dataRef` | Indigo 400 / 500 | `$ref` 句柄、`resources://` 标签、链接 |
| 终态/空闲灰 | `terminalMuted` | Gray 500 · Slate 500 | 终态锁定、空闲、卸载态 |
| 细边框 | `hairline` | 白基 / 黑基 12% | 全部 1dp 分隔线 |
| 代码底 | `codeBg` | 白基 / 深基 8% | 行内与块级代码底 |

## 2. 排印 Token（双轨分立）

| 轨道 | 字体 | 字号 | 规则 |
| --- | --- | --- | --- |
| 阅读轨（对话 / 长文 / Markdown） | Inter / Roboto | 正文 14~15sp，行高 1.5~1.6 | 标题级数严格；代码块微深底 + 横向平滑滚动 |
| 遥测轨（Trace-ID / 端口 / 参数 JSON / Schema / Token 计数 / 引擎名 / 时间戳） | JetBrains Mono / Roboto Mono | 11~12sp（微标注 10.5sp） | 强制等宽；微弱底色容器包裹 |

- 遥测内容出现于阅读轨文本中**必须**包等宽容器；阅读内容禁用等宽。
- 面向用户的相位/状态文字用人话中文，内部英文相位名禁直出。
- 字号收敛到既定阶梯（正文 / 列表 / 紧凑 / 遥测 / 微标注 / 标题各档，token 唯一出处 `lib/ui/tokens/`）；新增字号档位须先扩阶梯再使用，禁任意值。

## 3. 界面模块规格

### 3.1 输入条状态带

形态唯一：**底部输入面板顶缘内嵌状态带**。禁：顶部独立状态行、顶部常驻状态、系统 Overlay 悬浮窗（M3+ 另行评估）。`StatusCapsule` 组件仅限联调页等非输入场景复用。

| 项 | 规格 |
| --- | --- |
| 高度 | 30dp；空闲态收 0（AnimatedContainer 平滑，禁突跳） |
| 分隔 | 下缘 1dp hairline；文本输入区保持全宽 |
| 左位 | 7dp 语义状态点 + 等宽 11sp 相位文字，单行 ellipsis |
| 右位 | 运行态 `mm:ss` 计时；计时由状态带自管定时器，禁整页 setState 刷新 |
| 上下文胶囊 | 绑定态（私有=锁形 / 本地插件 / 公共）显示于左端；可点打开上下文菜单 |
| 主操作槽 | 无独立容器，图标融入药丸输入行，与左端「+」对称（同 48×48 热区，§4.4）。三态只换图标与颜色：空输入=terminalMuted 箭头（不可发送）／有输入=l1Info 箭头（可发送）／运行=danger stop（中止）。色彩 180ms 紧凑过渡确认相位，禁瞬时替换图标、禁形状随相位形变。可发现性多通道兜底：stop 图标语义 + 状态带执行中相位（§6 双通道合规）。**沿革**：2026-10-18 二次修订（用户拍板「与 + 对称、融入药丸」），替代同日「40×40 圆角方实底槽」，并作废原 P1-4「Crimson 实底高反差」拍板 |
| IME | 随输入面板整体位移（SafeArea），禁独立悬浮层 |

相位人话对照（左列内部名 → 右列显示文）：idle→空闲 / connecting→连接中 / thinking→思考中 / done→已完成 / failed→失败 / rejected→已拒绝 / breaker→工具报错，待处理 / fence→敏感信息，待确认。此表为**基线覆盖集**：新增相位按同一构词法（人话动作 + 「中 / 待处理」后缀）入表，语义色归 §1 四档之一，禁英文内部名直出。

### 3.2 双轨消息流

| 规则 | 规格 |
| --- | --- |
| 排布 | 阅读轨与操作轨一律同一纵轴；禁左右对投气泡 |
| 卡片结构 | 8~12dp 圆角，扁平内凹或微浮起；状态以左侧竖条表达，语义色映射按 §1（琥珀=待确认、Emerald=执行/成功、玫瑰=熔断/中止、灰=终态） |
| 参数/键值排版 | 一律两列：Key 等宽 11sp 次级灰、右对齐带冒号；Value 12sp 高亮白（遥测值保持等宽）。超 4 行默认折叠，尾行 `[展开全部 +N 项]` 扁平触发器；禁大段无排版 JSON |
| 错误呈现 | 一律等宽结构化摘要；禁整段直贴原始异常堆栈 |
| 终态呈现 | 交互终态一律转灰阶弱化：操作控件禁残留，替换为审计文本行（「✓ 已于 HH:mm …」「✕ 已拒绝（原因：…）」「⊘ Cancelled」）。工具执行卡（CallCard）终态**默认压缩单行**：「✓/✕/⊘ + 人话动作摘要」（灰阶，ellipsis），点击展开详情（工具名遥测/描述/结果全文，附「收起」回入口）；running/stuck 保持完整呈现（2026-10-18 修订：对话流默认只留「做了什么」，请求/返回细节点开才见） |

### 3.3 面板卡片（大厅 / 列表类模块）

| 规则 | 规格 |
| --- | --- |
| 布局 | 卡片阵列（控制台式高密度）；同页卡片结构规格一致 |
| 数值字段 | 卡内数值类内容（端口 / 延迟 / 计数等）一律遥测轨等宽 + 单位；禁阅读轨混排 |
| 在线/离线 | 状态点 + 文字双通道（§6），禁仅以绿点示意 |
| 准入/授权状态色 | 正常=L1、准入被拒=玫瑰、未授权/已卸载=灰阶；被拒禁与卸载态同灰阶混淆 |
| 开关控件 | 挂载类开关用微型物理开关质感；禁大圆角胶囊开关（总纲③） |

## 4. 交互质感细则

1. **触觉**：L2 拦截卡弹出=双击警示震动；Abort/熔断=重度确认震动；L1 静默执行与完成=极轻微 tick。
2. **动效**：禁 Spring；用 Decelerate / Ease-Out 紧凑减速曲线；转场 150~200ms；状态点仅颜色相位过渡，禁缩放/弹跳。
3. **边缘**：卡片分割一律 1dp 细边框（0.5~1dp，10%~15% 不透明度）；禁大范围弥散投影。
4. **触控热区**：可点击区域 ≥44×44dp——视觉元素可小（7dp 点、11sp 标注），以透明 padding 补足，视觉不变。
5. **长文本截断**：Trace-ID/哈希中段省略（`7f3a…9c1e`）+ 长按复制全串；URI/路径末尾省略 + 横向平滑滚动，禁随意折行；超宽工具名单行 ellipsis。
6. **空态与占位**：空会话=居中人话提示（限宽与消息流同轴）；加载占位禁高亮扫光，用单色暗调极慢渐隐。
7. **Token 化**：色彩/字体/圆角/边框/动效时长一律取 design tokens（Flutter `ThemeExtension`），组件内禁散落魔法值——tokens 唯一出处 `lib/ui/tokens/`。

## 5. 布局标尺

| 标尺 | 取值 |
| --- | --- |
| 基线网格 | 4dp；间距阶梯 4 / 8 / 12 / 16（紧凑微调 6 / 10 / 14 须落在网格系内，禁任意值） |
| 圆角分级 | Badge/标签 4dp；按钮/小容器 8~12dp；卡片取 token `cardRadius`=10；全局禁 >16dp |
| 边框 | 1dp hairline，token 唯一出处 |
| 宽屏限宽 | 消息流与输入区居中 720dp；空态提示 560dp |

- **阶梯封闭**：新增尺寸一律落本表阶梯内；确需新档位先扩本表并同步 token，禁组件内私自取值。

## 6. 无障碍红线

| 红线 | 规格 |
| --- | --- |
| 对比度 | 正文字色对底色 ≥4.5:1（WCAG AA）；11sp 级等宽微字 ≥3:1 |
| 双通道状态 | 禁仅以颜色传达状态：每个语义色必须伴随图标 / 形状 / 文字标签至少其一（色弱与强光下仅凭第二通道可判态） |
